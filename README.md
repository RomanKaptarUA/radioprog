# Radio Kevin

Вебсайт для пошуку європейських радіостанцій та українських хвиль. Список країн і станцій завантажується з [Radio Browser](https://www.radio-browser.info/).

Мова інтерфейсу автоматично змінюється разом із країною: використовується її основна мова (наприклад, французька для Франції та німецька для Швейцарії). Список країн у перемикачі завжди відображається англійською з назвою країни її рідною мовою в дужках, незалежно від мови інтерфейсу. Основні елементи інтерфейсу перекладені мовами країн каталогу. Для багатомовних країн автоматично обирається одна основна мова. Обрані станції зберігаються у браузері.

## Вимоги

- Node.js 20 або новіший
- npm (входить до складу Node.js)

Перевірити встановлення можна в терміналі:

```powershell
node --version
npm --version
```

## Запуск

У терміналі з кореневої папки проєкту:

```powershell
npm run dev
```

Режим розробки автоматично перезапускає сервер після змін у файлах. Для звичайного запуску:

```powershell
npm start
```

Зупинити сервер можна клавішами `Ctrl+C`. Порт можна змінити, задавши змінну середовища `PORT`.

## Структура

- `src/server.js` — HTTP-сервер і проксі до Radio Browser API
- `public/index.html` — багатомовний інтерфейс, пошук, обране та аудіоплеєр
- `public/radio-kevin-background.jpg` — фонове зображення сайту

Каталог показує до 24 популярних станцій на країну. Інформація про станції вимагає з’єднання з інтернетом; відсутні логотипи замінюються згенерованими локальними обкладинками. Старий список обраного для всього світу більше не використовується. Доступність прямого ефіру залежить від станції та її потоку.
